# Panel Hidrourgencias

## Desde celular

1. Abrir `hidrourgencias.cl/admin`.
2. Escribir usuario.
3. Escribir contraseña.
4. Presionar `Iniciar sesión`.
5. Presionar `Nuevo trabajo`.
6. Seleccionar comuna, tipo de propiedad y servicio.
7. Escribir o dictar la situación, intervención y resultado.
8. Agregar fotos desde cámara o galería.
9. Marcar portada, ordenar fotos y completar descripciones.
10. Guardar borrador.
11. Revisar `Vista previa`.
12. Publicar cuando esté correcto.

## Guardar borrador

1. Completar los campos disponibles.
2. Presionar `Guardar borrador`.
3. Volver a `Trabajos` para continuar más tarde.

## Editar trabajo publicado

1. Abrir `Trabajos`.
2. Seleccionar el trabajo.
3. Ajustar texto, fotos, portada o distribución.
4. Presionar `Publicar` para actualizar el contenido público.

## Archivar

1. Abrir el trabajo.
2. Presionar `Archivar`.
3. El trabajo deja de mostrarse en las páginas públicas sin borrar el registro.

## Cambiar Contraseña

1. Entrar al panel.
2. Abrir `Configuración`.
3. Escribir contraseña actual.
4. Escribir nueva contraseña.
5. Confirmar nueva contraseña.
6. Presionar `Actualizar contraseña`.
